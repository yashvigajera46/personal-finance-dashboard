# FinPulse Pro — Financial Analytics Dashboard 💜

FinPulse Pro is a lightweight, responsive financial tracking and cash-flow intelligence dashboard built with Python and Streamlit. Designed with session isolation, it gives each visitor a private sandbox to log transactions, monitor multi-currency budgets, and export financial statements on demand.

---

## 🌟 Key Features

- **Session-Based Privacy:** Each user gets an independent in-memory session—no shared entries, database leaks, or cross-user visibility.
- **Multi-Currency Support:** Track and view expenses and income separately in INR (₹), USD ($), EUR (€), and GBP (£).
- **Fast Numeric Entry:** Direct text input for amounts and budgets without stepper buttons.
- **Budget Tracking & Visual Alerts:** Real-time progress gauges and alerts when spending exceeds target caps.
- **Interactive Visualizations:** Dynamic donut charts, payment channel volume bars, and daily cash-flow breakdowns powered by Plotly.
- **Data Portability:** Generate safe, ASCII-compliant PDF financial statements and export ledgers directly to CSV.
- **Mobile-Responsive UI:** Custom CSS styling optimized for clean handheld navigation with a touch-friendly sidebar toggle.

---

## 🛠️ Tech Stack

- **Framework:** Streamlit
- **Data Processing:** Pandas
- **Visual Analytics:** Plotly Express
- **Document Generation:** FPDF
- **Deployment:** Streamlit Cloud
